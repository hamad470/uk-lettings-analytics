    Method

    How this was built

    Questions
    1. How long does referencing take, and what slows it down? 2. How are rents moving by region? 3. Can we spot tenancies at risk of early arrears better than the 30x affordability rule? 4. Can the numbers be trusted?
    Data
    Real referencing and payment records are personal and confidential, so a reproducible simulator (fixed seed) generates a lettings platform's data: 80 agents, ~26k applications, ~16k tenancies, ~150k rent payments. Regional rent levels are loosely calibrated to published ONS private-rent averages; seasonality, slower self-employed referencing and affordability-driven arrears are built in. Real-world mess is planted on purpose: duplicates, missing and mis-keyed incomes, bad rents, inconsistent region names and impossible timestamps.
    Tools
    Python and pandas for generation; DuckDB SQL for data-quality checks, a staging layer and reusable marts; scikit-learn for the model; a dependency-free HTML/SVG dashboard published on GitHub Pages, plus a Streamlit version for interactive exploration.
    Quality checks
    11 data-quality rules on raw data, 9 automated validation tests (reconciliation between marts and fact tables, funnel only narrowing, legal deposit cap, model beating random on unseen data). Right-censoring is flagged: the most recent month's conversion rate is low only because those applications have not had time to become tenancies.
    Model
    Logistic regression chosen for interpretability. Time-based split (train on older tenancies, test on newer ones) to avoid leaking future behaviour. A gradient-boosting challenger scored lower on the test period, so the simpler model was kept. Judged against the business rule at the same flag volume, not just on AUC.
    Use of AI
    An AI assistant helped scaffold code and draft documentation. Every output was checked: SQL results reconciled against pandas, model metrics re-derived, and synthetic behaviours checked against expectations. An early version showed 69% of students in arrears; investigating showed the simulator ignored guarantors, so it was fixed. Judgement calls (the arrears definition, the time split, excluding region, flagging small samples) were made by hand.
    Next steps
    Swap in real ONS Price Index of Private Rents data for the rent view; add confidence intervals to small-sample medians; monitor model calibration monthly; test whether faster referencing raises conversion.
